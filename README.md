# HPC
Репозиторий для лабораторных работ по дисциплине "Высокопроизводительные вычисления" Митрофановой Марии, группа 6133-ПМИ

Поскольку на моем ноутбуке отсутствует видеокарта от Nvidia, все ЛР выполнены на пк с данной видеокартой, а после залиты в гит. Вспомогательные файла, создаваемые VS, я не переносила.
