# ЛР1 - MatMul (Перемножение матриц)
Задача: реализовать алгоритм перемножения матриц

___
Был реализован простейший ijk-алгоритм умножения матриц для вычислений на центральном процессоре. При реализации в использовалась модель параллелизма, в которой каждая нить вычисляет свой собственный элемент результирующей матрицы. То есть, нить с глобальным индексом (i, j), вычисляемым как i = blockIdx.y * blockDim.y + threadIdx.y и j = blockIdx.x * blockDim.x + threadIdx.x, отвечает за расчёт элемента C[i][j]. В рамках одной нити вычисление элемента производится последовательно путём накопления суммы произведений элементов строки матрицы A и столбца матрицы B.

Так как матрица является двумерным объектом (несмотря на хранение в памяти в виде линейной развертки построчно), конфигурация исполнения ядра также организована в двумерном пространстве: и сетка блоков (grid), и сами блоки (block) имеют двумерную структуру размерности (dim_x, dim_y). 

___
Результаты работы представлены в виде графика в Excel. График показывает, что использование CUDA для перемножения матриц обеспечивает значительное ускорение вычислений по сравнению с последовательным алгоритмом на процессоре, причём прирост производительности растёт с увеличением размерности задачи. На малых матрицах эффективность ограничена накладными расходами на передачу данных между оперативной памятью и видеокартой.
