# ЛР4 - Function Approximation by a Polynomial Using a Genetic Algorithm

Для начала был сгенерирован набор зашумленных данных на CPU (хосте) по формуле полинома 4-й степени с добавлением равномерного шума. Далее реализуется генетический алгоритм. Сам алгоритм итерационен: поколения сменяют друг друга последовательно, и вычисления внутри каждого поколения можно распараллелить на GPU.

1. Генерация стартовой популяции. Коэффициенты полинома (гены) инициализируются случайными значениями из равномерного распределения в диапазоне [-10, 10]. Каждая нить GPU отвечает за одного индивида, что обеспечивает мгновенное заполнение популяции.

2. Фитнес-функция (Fitness). Для каждого индивида параллельно вычисляется максимальная абсолютная ошибка между истинными значениями y и значениями полинома на всех точках сетки. Каждая нить обрабатывает одного индивида, последовательно проходя по массиву данных.

3. Отбор (Selection). После вычисления Fitness массив особей копируется на хост, где сортируется по возрастанию ошибки. Лучшие 50% популяции остаются элитой для скрещивания, худшие 50% помечаются на замену (отбор вынесен на CPU из-за малого размера популяции).

4. Кроссовер. Параллельно на GPU для второй половины популяции создаются новые особи. Случайным образом выбираются два родителя из лучшей половины и точка разрыва. Коэффициенты до точки разрыва берутся у первого родителя, после – у второго. Данный процесс полностью независим для каждой нити и параллелится.

5. Мутация. После кроссовера с вероятностью 10% каждый коэффициент новой особи подвергается мутации. Мутация выполняется в том же ядре, что и кроссовер. Мутация также параллелится, так как применяется независимо к каждому гену в рамках нити.

На хосте после каждой генерации отслеживается индивид с минимальной ошибкой. В качестве ошибки использовался максимум среди модулей отклонения по точкам.
