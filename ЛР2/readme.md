# ЛР2 - Vector Sum (Сумма элементов вектора)
Задача: реализовать алгоритм сложения элементов вектора

___
В данной лабораторной работе распараллелена операция суммирования (редукции) элементов массива. Вместо последовательного накопления суммы в одном потоке CPU, вычисления распределяются между тысячами потоков GPU, что позволяет обрабатывать большие массивы за значительно меньшее время. Прямое атомарное сложение каждого элемента в общую переменную глобальной памяти сериализовало бы доступ к ней, превратив программу в последовательную и уничтожив выигрыш от GPU. Чтобы сохранить параллелизм и избежать гонок данных, каждый поток сначала накапливает частичную сумму в собственном регистре, затем потоки внутри одного варпа объединяют свои значения через быструю инструкцию *__shfl_down_sync*, что исключает затраты на работу с разделяемой памятью и явные барьеры синхронизации. Итоговые частичные суммы записываются в глобальную переменную через *atomicAdd* только от имени каждого варпа, что снижает количество конфликтов на шине памяти и дает правильный результат.

___
Результаты работы представлены в виде графика в Excel. График показывает, что использование CUDA для нахождения суммы элементов вектора обеспечивает значительное ускорение вычислений по сравнению с последовательным алгоритмом на процессоре, причём прирост производительности растёт с увеличением размерности задачи.
